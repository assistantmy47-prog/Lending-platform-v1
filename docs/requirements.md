This is the persistent, version-controlled requirements tally for the Refined Lending Platform. Requirements are initially captured at a high level and can be refined later into approved scope and acceptance criteria.

**Current status:** Draft / ongoing capture

## Register conventions

- Assign new entries sequential, permanent IDs (next: `REQ-004`).
- Preserve prior requirements when adding new ones.
- Categorise entries as functional, UX, or technical; categories may be refined as requirements mature.
- `Captured` indicates that a requirement has been recorded, not that it has been agreed, prioritised, or implemented.
- Capture priority, owner, dependencies and acceptance criteria when defined rather than assuming them.
- Update this file in the repository to retain a portable, auditable history of the evolving requirements.
